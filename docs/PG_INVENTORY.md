| sqlite_master | 15 modules | schema lives in lib/db/migrations/pg; drop runtime schema probes |
| json1 | 0 modules | jsonb operators (->, ->>) or decode in code |
| group_concat | 0 modules | string_agg(x, ',') |
| ifnull | 0 modules | COALESCE |
| glob | 0 modules | LIKE / ~ (regex) |
| scalar-max-min | 3 modules | GREATEST / LEAST |
| like-case | 10 modules | SQLite LIKE ignores ASCII case, PG LIKE does not: use lower(x) LIKE lower(?) or ILIKE |
| changes | 0 modules | RETURNING / RunResult.changes |
