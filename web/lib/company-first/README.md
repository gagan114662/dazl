# Company-first discovery

This is a separate, default-off engine candidate. Nothing in the existing finder calls it. The production adapter must bind the current tenant and attempt, the reviewed intent, and the existing holds before mounting it.

- Discover company hints, independently verify the owned website, then read a literal first-party or exact employer-linked dated signal. A search snippet, ATS board root, guessed domain, or missing date is not proof.
- The new adapters pass only settled, exact-citation company hints into independent website review. A different-origin citation needs an exact source-to-company assertion. The verifier never fetches the citation; it reserves and reads only the reviewed owned origin. The authoritative ports are not wired yet.
- Corroborate an observed official directory and buyer biography, then the current same-person public profile and the exact company-published work email. Show only a result bound to a current receipt from all existing holds.
- Before any paid batch, the caller must atomically reserve the whole batch across the same case budget used by both finders and the judge. Unknown usage stops later calls. The rolling quote is an estimate, not an invoice guarantee.
- The separate dynamic Claude wire and billing adapters are intentionally unmounted. Company page fetch requires an independently verified exact-destination, HTML-only, no-redirect transport. Never replay a paused turn automatically.
- Diagnostics preserve anonymous observed counts and hold reasons. A returned Ready row is not a UI impression. No private case, raw provider payload, or held identity belongs in a log.

The offline tests here are not the ten recorded PR replay cases or a live old-vs-new scorecard.
